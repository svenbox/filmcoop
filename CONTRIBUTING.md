# Bidra till film.coop

Tack för att du är intresserad av att bidra!

## Vad du kan bidra med

- **Ramverket** ([docs/ramverk.md](docs/ramverk.md)) — förslag på förbättringar
  av poängmodellen, fasindelningen eller utbetalningsordningen.
- **Crowdfunding** ([docs/crowdfunding.md](docs/crowdfunding.md)) — särskilt
  juridisk kompetens kring svensk kooperativ-rätt eller ekonomisk
  föreningsrätt, Finansinspektionens regelverk kring publika erbjudanden,
  eller teknisk integration mot betalningslösningar.
- **Kalkylbladet** ([tools/filmcoop_v1.xlsx](tools/filmcoop_v1.xlsx)) —
  förbättringar av mallen, buggar i formlerna.
- **Portalen** — sätt upp din egen instans (se [docs/setup.md](docs/setup.md))
  och rapportera buggar eller önskemål som issues.

## Hur du bidrar

1. Öppna ett issue för att diskutera större ändringar innan du lägger ner tid
   — särskilt sådant som rör poängmodellen eller waterfall-logiken, där
   ändringar påverkar hur befintliga produktioner räknar sina andelar.
2. Forka repot och gör din ändring i en egen branch.
3. Öppna en pull request med en tydlig beskrivning av vad och varför.

Mindre ändringar i dokumenten (typos, förtydliganden) är välkomna direkt som
PR utan föregående issue.

## Uppförande

Det här är ett litet, informellt projekt. Anta gott uppsåt och var
konstruktiv i diskussioner.
